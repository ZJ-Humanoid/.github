浙江人形机器人创新中心有限公司（以下简称“人形中心”）注册成立于2023年12月21日，由熊蓉教授及团队联合多家知名产业方共建，重点开展人形机器人“大小脑”关键技术研究和整机系统研发与应用。



2024年3月，人形中心发布首个初代样机“领航者1号”，身高150cm，体重50kg，拥有39个自由度，实现长距离稳定行走和全身协调舞蹈。



2024年8月，人形中心发布首个具备精确技能作业能力的人形机器人“领航者2号NAVIAI”，身高165cm、体重60kg、拥有41个自由度，凭借亲和外观、可靠硬件性能、精准操作等优势，获得市场广泛认可。团队采取功能-结构-外观一体化设计，使其在外形上更精美拟人的同时具备较高性能。NAVIAI突破长序列动作快速学习，高实时响应缓急自如；突破单策略网络运控小脑，实现多地形多扰动鲁棒适应；模仿学习强化学习融合，实现长时间稳定站立动作；开放未知环境下图像/语义高效探索导航。



人形中心目前在科研教育、商业服务、工业制造等场景与行业领军企业开展实质性商务合作，并成功实现部分场景的落地交付。
